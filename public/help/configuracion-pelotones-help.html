Gestión de Pelotones

¿Qué es esta pantalla?

Esta pantalla permite gestionar los Pelotones o unidades operativas. Cada pelotón tiene un código identificativo, una descripción y un color asociado que se utiliza en cuadrantes, informes y planificaciones.

  • Código: Identificador único del pelotón (ej.: 11, 111, 2JEFE3C…)
  • Descripción: Nombre o etiqueta del pelotón.
  • Color: Color visual asignado para identificarlo en tablas y cuadrantes.
Crear, Editar y Eliminar Pelotones

La tabla es editable directamente. Puedes modificar cualquier celda haciendo clic sobre ella.

  • Nuevo: Añade un pelotón vacío para rellenar sus datos.
  • Editar: Cambia código, descripción o color directamente en la tabla.
  • Eliminar: Usa el icono de papelera para borrar un pelotón.

Los cambios no se aplican hasta que pulses Guardar.

Acciones disponibles
  • Guardar: Aplica todos los cambios realizados.
  • Descartar: Revierte los cambios no guardados.
  • Exportar: Genera un archivo con la lista de pelotones.
  • Cambios pendientes: Indica cuántas filas han sido modificadas.
Consejos y Buenas Prácticas
  • Utiliza colores consistentes para facilitar la lectura en cuadrantes.
  • Evita modificar códigos si ya están en uso en servicios o planificaciones.
  • Revisa los cambios pendientes antes de guardar.
  • Usa descripciones claras para identificar fácilmente cada pelotón.
