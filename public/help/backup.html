Copias de Seguridad

Exportar copia de seguridad

Permite exportar información de la aplicación en formato JSON para conservar una copia de seguridad o trasladar los datos a otra instalación.

1. Seleccionar el periodo

Indica las fechas de inicio y fin que delimitan los registros que deseas exportar.

  • Desde: Fecha inicial del periodo.
  • Hasta: Fecha final del periodo.
  • El intervalo se aplica a las tablas de trabajo seleccionadas.
2. Definir la carpeta de destino

Introduce un nombre para identificar la carpeta de la exportación. No es necesario indicar una ruta completa, ya que la aplicación utiliza el área segura de almacenamiento de copias de seguridad del servidor.

Dentro de la carpeta indicada se creará automáticamente una subcarpeta con el nombre:
backup_AAAAMMDD_HHMMSS
El nombre incorpora la fecha y hora de creación.
3. Seleccionar las tablas de trabajo

Marca las tablas cuyos registros deseas incluir en la exportación. Estas tablas utilizan el intervalo de fechas indicado.

  • Auditorías de accesos (login).
  • Auditorías de turnos.
  • Auditorías de planificación.
  • Periodos y ejecuciones de requisitos de agentes.
  • Planes de planificación y sus asignaciones.
  • Cuadrantes de planificación e importaciones.
  • Otras tablas operativas disponibles en el listado.

Puedes marcar individualmente las tablas o utilizar Marcar todos para seleccionar todas las disponibles.

4. Seleccionar los catálogos maestros

De forma opcional, puedes incorporar los catálogos maestros de la aplicación.

  • Provincias y comunidades.
  • ARS (unidades).
  • Empleos.
  • Pelotones.
  • Situaciones de agente.
  • Niveles de grupo.
  • Otros catálogos disponibles.
Los catálogos maestros se exportan completos, independientemente del intervalo de fechas seleccionado.
5. Generar la exportación
  1. Pulsa Vista previa para comprobar los datos que se van a exportar.
  2. Revisa las tablas y los registros incluidos.
  3. Pulsa Exportar para generar la copia de seguridad.
  4. La aplicación almacenará los archivos JSON en la carpeta correspondiente del servidor.
Importar copia de seguridad

Permite recuperar información previamente exportada, seleccionando la copia de seguridad y las tablas que se desean incorporar a la base de datos.

1. Seleccionar la copia de seguridad

En el campo Copia de seguridad, selecciona una de las copias previamente generadas mediante la función de exportación.

  • Se muestran las copias de seguridad disponibles.
  • Selecciona la copia que contiene la información que deseas recuperar.
  • El icono de actualización permite refrescar el listado de copias disponibles.
2. Establecer el intervalo de fechas

Puedes indicar las fechas de inicio y fin para limitar los registros que se van a importar en las tablas de trabajo.

  • Desde: Fecha inicial del intervalo.
  • Hasta: Fecha final del intervalo.
El intervalo de fechas solamente afecta a las tablas de trabajo seleccionadas. Los catálogos maestros se importan siempre completos.
3. Seleccionar las tablas que se van a importar

Una vez seleccionada la copia de seguridad, aparecerán las tablas disponibles para su recuperación.

  • Selecciona las tablas que deseas recuperar.
  • Puedes seleccionar una o varias tablas.
  • Las tablas de trabajo respetarán el intervalo de fechas indicado.
  • Los catálogos maestros se importarán completos.
4. Ejecutar la importación
  1. Comprueba que has seleccionado la copia correcta.
  2. Revisa el intervalo de fechas.
  3. Selecciona las tablas que deseas importar.
  4. Pulsa el botón Importar.
  5. Espera a que finalice el proceso de recuperación.
Control de duplicados: Los registros existentes no se duplican. Se conserva el identificador original de los registros importados.
Diferencias entre tablas de trabajo y catálogos maestros

La aplicación distingue dos tipos de información a la hora de realizar las copias de seguridad:

Característica Tablas de trabajo Catálogos maestros
Selección Individual o todas. Individual o todos.
Filtro por fechas Sí. No.
Exportación Registros del periodo seleccionado. Contenido completo.
Importación Registros del periodo seleccionado. Contenido completo.
Recomendaciones y notas importantes
  • Realizar copias periódicas: Es recomendable generar copias de seguridad con regularidad para disponer de información recuperable ante cualquier incidencia.
  • Seleccionar correctamente el periodo: Comprueba las fechas de inicio y fin antes de exportar o importar información.
  • Identificar las copias: Utiliza nombres descriptivos para las carpetas de destino, facilitando su localización posterior.
  • Almacenamiento: Las copias se guardan en el área segura de backups configurada en el servidor, no en una carpeta de descarga del navegador.
  • Importación selectiva: No es necesario recuperar todas las tablas. Selecciona únicamente aquellas cuya información necesites incorporar.
  • Identificadores originales: Durante la importación se conservan los identificadores originales y se evita duplicar registros existentes.
  • Catálogos maestros: Recuerda que no están sujetos al intervalo de fechas. Siempre se exportan e importan completos cuando se seleccionan.
  • Precaución: Antes de realizar una operación de recuperación, comprueba que has seleccionado la copia de seguridad y las tablas correctas.
