Acciones Masivas de Agentes


🧭 ¿Qué puedes hacer?
  • Dar de alta múltiples agentes mediante ficheros CSV.
  • Dar de baja agentes de forma masiva mediante ficheros CSV.
  • Gestionar bajas manuales seleccionando agentes individualmente.
⚙️ Opciones principales
CSV Altas
Carga el archivo de altas masivas.
Ejecutar
Procesa la operación de altas.
Errores CSV
Descarga incidencias detectadas.
CSV Bajas
Carga fichero para bajas masivas.
Bajas
Ejecuta la operación de bajas.
Baja selección
Elimina agentes seleccionados.
📂 Área de trabajo
  • Se muestra la lista de agentes o TIPs según operación.
  • Selección individual de agentes para bajas manuales.
  • Flujo recomendado
    • Subir archivo CSV o seleccionar agentes.
    • Validar datos y revisar errores. Ejecutar
⚠️ Consideraciones y buenas prácticas
  • Verifica el formato CSV antes de cargar.
  • Revisa errores antes de ejecutar.
  • Las bajas son lógicas y no eliminan físicamente los registros.
  • “Sin datos” indica ausencia de registros cargados.
  • Usa siempre la plantilla oficial.
  • Realiza pruebas con pocos registros antes de cargas masivas.
