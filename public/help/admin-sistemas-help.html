Módulo Sistema · Ayuda General

Gestión de ARS / Unidades

Esta pantalla permite gestionar las Unidades del sistema: ARS, GRS y otras unidades operativas.

  • Unidad: Código identificativo (ARS, GRS1, GRS2…)
  • Domicilio / Población / Provincia: Datos administrativos.
  • Teléfono / Email: Datos de contacto.
  • Oficial al Mando: Responsable de la unidad.
  • Color: Color asignado para informes y cuadrantes.
Acciones
  • Nuevo: Añade una unidad.
  • Editar: Modifica cualquier celda directamente.
  • Eliminar: Borra una unidad si no está en uso.
  • Guardar / Descartar: Aplica o revierte los cambios.
  • Exportar: Descarga la tabla.
Gestión de Usuarios

Permite administrar los usuarios del sistema, sus roles, estado y accesos.

  • TIP: Identificador del usuario.
  • ID: Identificador interno.
  • Nombre / Email: Datos personales.
  • Rol: admin, supervisor, operador, consulta.
  • ARS: Unidades a las que pertenece.
  • Estado: Activo / Inactivo.
  • Intentos / Bloqueado Hasta: Control de seguridad.
  • Último Login / Cambio Password: Auditoría básica.
Acciones
  • Nuevo: Crear usuario.
  • Editar: Modificar datos directamente.
  • Bloqueo: Control automático por intentos.
  • Guardar / Descartar: Confirmar o revertir cambios.
  • Exportar: Descargar listado.
Auditoría de Login

Muestra todos los accesos al sistema, permitiendo filtrar por usuario, email, IP o fecha.

  • Fecha / Hora: Momento exacto del acceso.
  • Usuario / Email: Identificación del usuario.
  • Resultado: OK / Error.
  • IP: Dirección desde la que se accedió.
  • User-Agent: Navegador y sistema operativo.
  • Exportar: Descargar informe.
Gestión de Roles

Define los roles del sistema y si son de sistema o personalizables.

  • ID / Nombre: Identificación del rol.
  • Observaciones: Información adicional.
  • Sistema: Indica si es un rol interno no editable.
  • Activo: Permite activar o desactivar roles.
Acciones
  • Nuevo: Crear rol.
  • Editar: Modificar nombre u observaciones.
  • Guardar / Descartar: Confirmar o revertir cambios.
Gestión de Permisos

Aquí se gestionan los permisos individuales: qué acciones puede realizar cada rol sobre cada recurso.

  • Recurso: Módulo del sistema.
  • Acción: crear, editar, eliminar, leer, validar, copiar…
  • Clave: Identificador técnico del permiso.
  • Descripción: Explicación del permiso.
Acciones
  • Nuevo: Crear permiso.
  • Editar: Modificar cualquier campo.
  • Eliminar: Borrar permisos no usados.
  • Guardar / Descartar: Confirmar o revertir cambios.
Matriz de Permisos

Vista global que muestra qué acciones puede realizar cada rol sobre cada recurso.

  • Columnas: Roles del sistema.
  • Filas: Recursos y acciones.
  • Casillas: Permiso otorgado (☒) o no otorgado (☐).
  • Actualizar: Guarda los cambios realizados.
  • Exportar: Descarga la matriz completa.
