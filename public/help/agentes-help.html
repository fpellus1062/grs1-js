Listado de Agentes


Cabecera

En la cabecera superior de la pantalla a la izquierda, ofrecemos información básica del listado de agentes, como el número total de agentes, el número de agentes seleccionados por el check y el número de agentes ocultos.

Opciones Principales:

  • Filtro Botón de filtro que nos permite mostrar u ocultar agentes según su situación (activos, inactivos o todos).
  • Nuevo Agente El sistema abre una ventana (modal) para su alta, mediante un formulario.
  • Cuadrante Botón que nos muestra una ventana (modal), donde podremos ver el/los cuadrantes asociados al agente.
  • Refrescar En este botón podremos refrescar la pantalla, lo que es útil para actualizar la información de los agentes tras realizar cambios en su ficha.
  • Exportar Botón que permite exportar el listado de agentes a un archivo Excel, incluyendo toda la información visible en la tabla.

Situación

Este es un campo que informa del estado de disponibilidad de un agente, en el largo plazo. Puede tener incidencia en la asignación de servicios, de tal forma que el sistema podrá nombrar de manera automática servicios asociados a esta situación.

Ejemplo: Si un agente, en la nueva creación de un cuadrante, el sistema podrá asignar de forma automática el servicio de baja a todo el cuadrante de dicho agente.

Orden

Es el ordinal que recibe un agente tras su nombramiento. Este campo forma parte del algoritmo de cálculo del escalafón del agente, compuesto por:

  • Jerarquía
  • Fecha de Nombramiento
  • Nº de Orden
Aptitudes

Campo que define los cursos y especialidades de un agente. Es un campo compuesto sujeto a un estricto orden:

Aptitud (4 caracteres) + espacio + @ + espacio

Se recomienda crear un nomenclátor estándar para cada aptitud.

PEI

Plan de Emergencia Interior. Sistema organizativo y de procedimientos para la gestión de accidentes.

Se activa mediante interacción (click) y tiene tres valores: Nulo / Sí / No.

PAEF

Plan de Atención de Emergencias. Medidas de prevención y respuesta ante situaciones de emergencia en el ámbito de la seguridad y protección ciudadana.

Se activa mediante interacción (click) y tiene tres valores: Nulo / Sí / No.

Fecha de Nombramiento

Es la fecha en la que el agente se incorpora al cuerpo y que posteriormente cambia conforme recibe nuevos nombramientos.

Escalafón

Es la estructura jerárquica que define la posición del agente dentro del cuerpo, la cual cambia conforme recibe nuevos nombramientos.

Esta estructura es clave dentro del escalafón del agente, compuesto por:

  • Jerarquía Empleo
  • Fecha de Nombramiento
  • Nº Orden
Operativa de Baja

Si pulsamos el botón de baja, el sistema nos preguntará si queremos dar de baja al agente. Si confirmamos, el sistema dará de baja al agente, lo que implica que el agente dejará de estar disponible para la asignación de servicios, pero no se eliminará su ficha. Esto es útil para mantener un registro histórico de los agentes que han formado parte del cuerpo, incluso aquellos que ya no están activos.

Operativa de Baja (Nota)

Notas al procedimiento de baja de un agente.

Atención: Esta acción es reversible, pero se recomienda precaución al dar de baja a un agente.

Importante: Una vez dado de baja, el agente no podrá ser reasignado a servicios activos.

Nota: Podemos volver a dar de alta al agente, pulsando el icono de recuperar. Este habrá sustituido a la papelera inicialmente, y al pulsarlo, el agente volverá a estar disponible para la asignación de servicios.
